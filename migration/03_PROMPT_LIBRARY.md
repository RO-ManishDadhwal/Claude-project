# 4. Reusable Prompt Library

Prompts worth keeping, extracted from the sources. **Original wording is
preserved.** Where formatting is improved, the improvement is limited to
unambiguously cosmetic changes — whitespace, list markers, code fencing,
consistent placeholder syntax — and the original is retained beside it so the
edit is always reversible.

Wording, ordering of instructions, and emphasis are **not** changed. If a prompt
looks like it could be improved substantively, that suggestion goes in the
`Notes` field as a suggestion, and the prompt itself stays as written.

## Entry format

Each prompt is recorded as:

```
### PROMPT-0000 — <short descriptive name>

- **Source:** <FILE-/CONV- ID + locator>
- **Date:** <as stated in source, or `not stated in source`>
- **Project:** <PROJ- ID or `unassigned`>
- **Purpose:** <what it was used for, per the source>
- **Variables:** <placeholders the prompt expects>
- **Reformatted:** <yes/no — if yes, what changed, cosmetically>
- **Notes:** <caveats, or suggestions offered but not applied>

**Original (verbatim):**

> ...

**Reformatted (cosmetic changes only, if applicable):**

> ...
```
